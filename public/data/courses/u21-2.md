:::question{title="竞争有多激烈：CRn 和 MS 怎么算？", hint="先想：『头部垄断没』和『某个竞品强不强』，是两个数字还是同一个？"}
小北要评估便携榨汁杯的竞争。mentor 说：头部垄没垄断、单个竞品强不强，得用两个不同指标。分别怎么算？

:::reveal{title="看解析：市场集中度（CRn）与竞品份额（MS）"}
竞争态势靠两个指标拆开看：整体垄断程度，和单个竞品话语权。

:::formula{
  title="市场集中度（CRn）：头部品牌垄断程度"
  theme="coral"
  expr="CRn =（前n家品牌销售额 / 全市场总销售额）× 100%"
  vars=[
    {sym:"n", mean:"取前几名，常用 CR3 / CR5 / CR10"},
    {sym:"全市场总销售额", mean:"该品类全部品牌销售额合计"}
  ]
}

:::formula{
  title="竞品份额（MS）：单一竞品话语权"
  theme="mint"
  expr="MS = 某竞品品牌销售额 / 全市场总销售额 × 100%"
  vars=[
    {sym:"某竞品品牌销售额", mean:"目标竞品在统计期内的销售额"},
      {sym:"全市场总销售额", mean:"同口径市场总额"}
  ]
}

市场进入难度评估：结合市场集中度、竞品份额、进入壁垒（资金、技术、渠道）综合判断。两个指标配合进入壁垒，才看得清新品牌入场难度。
