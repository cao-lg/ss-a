市场与商品核心指标体系是选品数据分析的核心支撑，围绕"市场潜力"与"竞争态势"两大核心维度搭建，涵盖市场规模、增长率、市场集中度等关键指标，既能量化市场基本面，又能拆解竞争格局，为选品决策提供可落地、可验证的数据依据，规避经验选品的盲目性。

## 市场规模与增长率：解决"市场有多大、增长快不快"

核心聚焦"市场容量天花板"与"增长潜力"，为选品方向提供基础判断，避免进入萎缩或饱和市场。

:::cards{
  title="市场规模（GMV）：两种测算口径"
  theme="mint"
  items=[
    {title:"销售额口径", desc:"市场规模=∑（头部竞品销售额+中小品牌估算值+未统计品牌补全值），适用于客单价稳定的品类。"},
    {title:"销量口径", desc:"市场规模=∑（全渠道销量数据），适用于客单价差异较大的品类。"}
  ]
}

:::formula{
  title="市场增长率（GR）：判断市场所处阶段"
  theme="amber"
  expr="GR =（当期市场规模 - 上期市场规模）/ 上期市场规模 × 100%"
  vars=[
    {sym:"当期市场规模", mean:"本期（年/季）该品类商品总销售额或总销量"},
    {sym:"上期市场规模", mean:"上一期同口径市场规模，用于对比增长"}
  ]
  note="GR 用于判断市场阶段：导入期 / 成长期 / 成熟期 / 衰退期。"
}

## 市场集中度与竞品份额：解决"竞争有多激烈、能不能进去"

核心聚焦"市场竞争格局"与"头部品牌垄断程度"，评估新品牌入场难度与生存空间。

:::formula{
  title="市场集中度（CRn）：头部品牌垄断程度"
  theme="coral"
  expr="CRn =（前n家品牌销售额 / 全市场总销售额）× 100%"
  vars=[
    {sym:"n", mean:"取前几名，常用 CR3 / CR5 / CR10"},
    {sym:"全市场总销售额", mean:"该品类全部品牌销售额合计"}
  ]
}

:::formula{
  title="竞品份额（MS）：单一竞品话语权"
  theme="mint"
  expr="MS = 某竞品品牌销售额 / 全市场总销售额 × 100%"
  vars=[
    {sym:"某竞品品牌销售额", mean:"目标竞品在统计期内的销售额"},
    {sym:"全市场总销售额", mean:"同口径市场总额"}
  ]
}

市场进入难度评估：结合市场集中度、竞品份额、进入壁垒（资金、技术、渠道）综合判断。

为方便快速查阅、记忆核心选品指标，现将前文涉及的市场、商品相关指标汇总整理，具体说明如表2-1所示。

| 指标层级 | 指标名称 | 内涵 | 计算应用 |
| --- | --- | --- | --- |
| 市场规模与增长类 | 市场规模（GMV） | 特定时期内某品类商品的总销售额或总销量 | 销售额口径=∑头部竞品销售额+中小品牌估算值 销量口径=∑全渠道销量 |
| 市场规模与增长类 | 市场增长率（GR） | 当期市场规模相对上期的增长比例 | （当期规模-上期规模）/上期规模×100% |
| 市场规模与增长类 | 市场渗透率（PR） | 目标客群中使用该品类商品的比例 | 使用用户数/目标客群总数×100% |
| 市场集中度与竞品类 | 市场集中度（CRn） | 前n家头部品牌的市场份额总和 | （前n家销售额/全市场总额）×100% |
| 市场集中度与竞品类 | 竞品份额（MS） | 单个竞品品牌的市场销售额占比 | 某竞品销售额/全市场总额×100% |
| 市场集中度与竞品类 | 进入壁垒（EB） | 进入市场所需的资金、技术、渠道等门槛 | 无固定公式，结合行业特性评估 |
