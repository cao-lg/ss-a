:::question{title="三大目标怎么落到商品角色上？", hint="先猜：波士顿矩阵把商品分成四类，它们分别扛哪个目标？"}
mentor 说用波士顿矩阵筛选爆款、引流款、利润款。你先想：明星、现金牛、问题、瘦狗这四类，分别该扛三大目标里的哪一个？

:::reveal{title="看解析：波士顿矩阵四类 = 三种商品角色"}
用波士顿矩阵把商品分成明星 / 现金牛 / 问题 / 瘦狗，正好对应选品要的三种角色：爆款、利润款、引流款。

:::cards{
  title="波士顿矩阵四类与商品角色的对应"
  theme="amber"
  items=[
    {title:"明星 → 爆款", desc:"高增长率+高份额，需求旺、优势强，作核心主推，扛「短期销量+长期利润」。"},
    {title:"现金牛 → 利润款", desc:"低增长率+高份额，市场成熟、利润稳，靠规模效应赚稳定钱，扛「长期利润」。"},
    {title:"问题 → 引流款", desc:"高增长率+低份额，潜力大、优势不足，低价培育客群，扛「品牌引流」。"},
    {title:"瘦狗 → 淘汰/试水", desc:"低增长率+低份额，市场萎缩、竞争烈，避免浪费，仅小量试水。"}
  ]
}
