一个活动刚上线一周，mentor 问你「灵不灵」。先凭直觉答：你会拿这一周去跟谁比，才能最快看出效果？

:::reveal{title="看解析：环比，盯的是『相邻这一波』"}
环比是**当前统计周期**与**相邻上一周期**的数据对比，核心捕捉短期（周、月、季度）指标变化，反映策略调整的即时效果。常见周期为日、周、月环比。

    {title:"看的是短期", desc:"紧跟刚发生的动作，反映策略调整的即时效果。"},
    {title:"抓的是波动", desc:"指标突然涨落，便于快速定位近期异常。"}
  ]
}
:::

:::question{title="环比增长率到底怎么算？拿真实数据练一把", hint="先猜：day2 曝光 4000、day1 曝光 3200，增长率该用哪个做分母？"}
mentor 甩来破壁机预热数据：day2 曝光 4000 次、day1 曝光 3200 次。你觉得这个日环比该几除几，结果是多少？

:::reveal{title="看解析：环比增长率公式 + 真算一遍"}
以「焕新家电」迷你破壁机双11预热为例，看环比怎么反映策略效果。

:::formula{
  title="环比增长率"
  expr="环比增长率 = (本期数据 - 上期数据) / 上期数据 × 100%"
  vars=[
    {sym:"本期数据", mean:"当前统计周期的数值"},
    {sym:"上期数据", mean:"相邻上一周期的数值"}
  ]
  note="结果为正对应指标上升，为负对应下降；常用于监测日/周/月级波动。"
}
:::

第2天**曝光量4000次**、第1天3200次，日环比 **+25%**（=(4000-3200)/3200×100%），反映触达范围扩大，或为抖音增投、小红书达人笔记发布所致。注意：分母是**上期(3200)**，不是本期。

:::question{title="某天流量暴涨，能直接算『策略有效』吗？", hint="先想：如果暴涨是因为临时发了一张大额优惠券，这能算常态成效吗？"}
小北发现某天因临时发大额券，流量暴涨。她激动地写结论「策略大获成功」。mentor 摇头——你觉得缺了什么？

:::reveal{title="看解析：排除偶然因素，拉满连续周期"}
> 需排除单日流量高峰、突发优惠等偶然因素，结合 **3 个以上连续周期**数据综合判断，环比结论才站得住。

单日暴涨可能是优惠刺激的一次性结果，不代表策略可持续。只有跨多个连续周期看，才能区分「真趋势」与「假波动」。
