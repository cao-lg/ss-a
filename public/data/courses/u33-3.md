# 同比分析：长期趋势判断

## 学习目标

- 理解同比分析：与上年同期对比，排除季节/大促干扰，判断长期趋势
- 掌握同比增长率公式（针对大促可细化为“大促同期同比”）
- 掌握转化漏斗分析：六大节点拆解流量流失
- 掌握四类多触点归因模型及适用场景

同比是**当前周期**与**上年同期**数据对比，用于衡量长期指标变化，排除季节性、大促周期干扰，精准评估年度效能提升。针对大促可细化为“大促同期同比”。

:::formula{
  title":同比增长率"
  expr="同比增长率 = (本期数据 - 上年同期数据) / 上年同期数据 × 100%"
  vars=[
    {sym:"本期数据", mean:"当前统计周期的数值"},
    {sym:"上年同期数据", mean:"上一年度同一周期的数值"}
  ]
  note="大促可细化为“大促同期同比”，剔除季节/大促共性因素，真实反映效能提升。"
}

家电行业存在显著的**大促周期**与**季节性**双重特征：双11、618 是全年销量峰值，空调夏季（6-8月）旺季、冬季（12-2月）淡季，波动可达数倍。仅看环比易因季节红利误判，需用同比剔除共性因素。

- 空调年中大促：今年128万元 vs 上年同期92万元，同比增长 **≈39.1%**（=(128-92)/92×100%），真实反映新品升级（一级能效、智能控温）+ 多渠道优化带来的效能提升。
- 电暖气：Q3曝光8.5万 vs Q2 3.2万，环比 **+165.6%**（季节驱动，非策略效能）；同比去年Q3 9.2万，同比增长 **≈-7.6%**，说明今年推广触达能力弱化，需优化旺季策略。

## 转化漏斗分析

转化漏斗分析是营销推广深度分析核心方法，以“用户行为递进路径”为核心，将推广全流程拆为“曝光→点击/浏览→加购→下单→支付→完成交易”六大关键转化节点，通过计算各节点转化率、流失率及跨节点关联度，精准定位流量流失区与流程断点，为优化提供方向。其核心价值是打破单一视角，全链路拆解问题，避免优化盲目性，实现全流程闭环分析。

## 多触点归因分析

在多渠道推广场景中，用户转化往往需经过多个渠道触点触达，如用户先刷到抖音信息流种草，再通过淘宝直通车进店下单，仅按最终成交渠道归因会高估单一渠道价值，低估辅助渠道作用。多触点归因模型通过量化各渠道在转化全链路中的贡献占比，解决“功劳分配”问题，为精准预算分配、渠道策略优化提供科学依据，是推广效果深度复盘的进阶工具。

结合家电电商推广特性，核心多触点归因模型分为四类，各模型适用场景、计算逻辑及实操要点如下：

易观方舟V5.2新增站内归因分析模型，如图3-10，更好地评估站内用户触点对总体转化所作出的贡献；在分析模型中支持维度表扩展，涉及商品、课程、企业等实体可以被快速调用；细分维度可以选择数据范围，更好地提升了查看数据的用户体验等。

以电商平台为例，在产品中会有不同的引流坑位，比如banner、金刚位、直播入口、有好货、每日推荐等等，通过不同的路径引导用户完成最终的下单支付，运营人员要想让流量收益最大化，就需要分析评估各个坑位对目标的贡献度，从而指导优化。

“流量不等于留量，留量不等于转化”，归因分析模型就能用于准确评估站内的用户触点对总体转化目标达成所作出的贡献。
