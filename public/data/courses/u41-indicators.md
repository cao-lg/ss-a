## 学习目标

- 像数据分析师一样提问： "卖了多少、赚了多少、卖得好不好、库存合不合理、客户值不值"
- 掌握五层指标体系，能在真实业务场景中快速定位该看哪个指标
- 能用指标之间的公式关系，反推业务问题

## 第一层：规模体量层 —— "卖了多少"

销售额不是凭空来的。它由两个更基础的量相乘得到。

**核心公式：销售额 = 销售量 × 产品价格**

:::checkpoint{
  type="fill"
  scenario="你看到后台显示：本周卖了 2,300 台空气炸锅，累计销售额 46 万元。"
  question="如果每台价格相同，这台空气炸锅的单价是多少元？"
  answer="200"
  hints=["单价 = 总额 ÷ 数量。","46 万 ÷ 2300 = ？先把 46 万写成 460000。"]
  feedback="460000 ÷ 2300 = 200。这就是规模层的基本拆解：销售额=销售量×产品价格。"
  unlock="知道这个关系后，下次销售额跌了，你可以直接问：是卖得少了，还是降价了？"
}

除了金额和数量，还要看订单活跃度：

:::cards{
  title="规模体量层：订单活跃度指标"
  items=[
    {title:"订单数量", desc:"客户下了多少单，反映交易频次"},
    {title:"有效 / 无效订单", desc:"二者结合算出订单有效率；无效单多通常意味着前端体验或地址校验问题"}
  ]
}

:::checkpoint{
  type="multiple_choice"
  scenario="本周有 1000 个订单，其中 50 个因地址错误被取消。"
  question="订单有效率是多少？"
  options=["90%","95%","5%","85%"]
  answer="95%"
  hints=["有效订单 = 1000 - 50 = 950。","有效率 = 有效订单 ÷ 总订单。"]
  feedback="有效订单 950 ÷ 总订单 1000 = 95%。无效订单太多通常意味着前端下单体验或地址校验出了问题。"
  unlock="订单有效率下降时，可以先排查客服取消原因，而不是急着改价格。"
}

## 第二层：盈利水平层 —— "赚了多少"

销售额高不等于赚钱。我们要看毛利和毛利率。

- **销售毛利 = 销售收入净额 − 销售成本**
- **销售毛利率 = (销售毛利 ÷ 销售额) × 100%**

:::checkpoint{
  type="fill"
  scenario="某款破壁机销售额 10 万元，进货成本 6 万元。"
  question="这款破壁机的销售毛利率是多少？（只写数字，不要百分号）"
  answer="40"
  hints=["毛利 = 10 万 - 6 万 = 4 万。","毛利率 = 毛利 ÷ 销售额 × 100。"]
  feedback="毛利 4 万 ÷ 销售额 10 万 = 40%。毛利率衡量的是'每卖 100 元能留下多少'。"
  unlock="不同品类毛利率差异很大。比较业绩时，应该横向比毛利率，而不是只比销售额。"
}

## 第三层：转化效率层 —— "卖得好不好"

有人来看，有没有人买？买了又退了多少？

:::cards{
  title="转化效率层：看买与退"
  items=[
    {title:"订单转化率", desc:"成交客户数 ÷ 同期访问客户数，低说明流量来了没转化"},
    {title:"订单退货率", desc:"退货数量 ÷ 同期成交产品总数，反映商品/描述匹配度"}
  ]
}

:::checkpoint{
  type="multiple_choice"
  scenario="详情页来了 10000 人，最后下单 200 人。"
  question="订单转化率是多少？"
  options=["0.2%","2%","20%","200%"]
  answer="2%"
  hints=["转化率 = 成交客户数 ÷ 访问客户数。","200 ÷ 10000 = 0.02。"]
  feedback="200 ÷ 10000 = 2%。转化率低说明'流量来了但没转化'，可能是详情页、价格或评价的问题。"
  unlock="2% 只是行业平均水平。如果你的转化率低于 1%，优先优化详情页前 3 屏。"
}

## 第四层：库存健康层 —— "库存合不合理"

卖得好，库存跟不上会断货；卖不动，库存积压会占资金。

:::cards{
  title="库存健康层：动销与滞销"
  items=[
    {title:"动销率", desc:"有销售记录的商品品种数 ÷ 仓库总品种数，看需求热度"},
    {title:"滞销率", desc:"无销售记录的滞销品种数 ÷ 企业总产品数，看积压风险"}
  ]
}

:::explore{
  title="如果你是店长"
  scenario="焕新家电某款破壁机这周销量忽高忽低：周一 50 台，周二 5 台，周三 60 台。仓库还剩 200 台。"
  choices=[
    {"text":"优先看动销率，判断它是不是整体热卖款", "feedback":"这是一个合理的方向。", "insight":"动销率高说明这款商品在'被买走'，但忽高忽低可能是促销或周末效应，要结合时间维度看。"},
    {"text":"优先看滞销率，判断它是不是积压品", "feedback":"也有道理，但这里销量不算低。", "insight":"滞销率是'完全没卖出'的品种占比。这款有销量，问题更可能是波动大，而不是滞销。"},
    {"text":"两个都看，还要看退货率", "feedback":"最完整的思路。", "insight":"实战中要组合看：动销率看需求，滞销率看积压，退货率看质量/描述是否匹配。"}
  ]
}

## 第五层：客户价值层 —— "客户值不值"

最后，要看每个客户带来多少价值。

:::cards{
  title="客户价值层：客单与连带"
  items=[
    {title:"客单价", desc:"销售额 ÷ 同期成交客户数，低时可凑单满减、搭配套餐提升"},
    {title:"连带率", desc:"销售产品总数量 ÷ 同期成交订单数，越高说明一次买得越多"}

}

:::checkpoint{
  type="fill"
  scenario="本周有 1500 位客户下单，总销售额 45 万元。"
  question="客单价是多少元？"
  answer="300"
  hints=["客单价 = 销售额 ÷ 成交客户数。","45 万 ÷ 1500 = ？"]
  feedback="450000 ÷ 1500 = 300 元。客单价低时，可以通过凑单满减、搭配套餐来提升。"
  unlock="连带率越高，说明客户一次买得越多。客单价 × 连带率是提升销售额的两个杠杆。"
}

## 小结：一张图串起来

五层指标不是孤立的，而是从外到内、从粗到细地解剖一笔生意：

```
规模体量层  → 卖了多少（销售额=量×价）
盈利水平层  → 赚了多少（毛利率）
转化效率层  → 卖得好不好（转化率、退货率）
库存健康层  → 库存合不合理（动销率、滞销率）
客户价值层  → 客户值不值（客单价、连带率）
```

:::checkpoint{
  type="multiple_choice"
  scenario="老板说：'本周销售额涨了，但毛利下降了。'"
  question="最可能的原因是？"
  options=["员工偷懒","打折促销拉高了销量但拉低了毛利","客户变少了","库存增加了"]
  answer="打折促销拉高了销量但拉低了毛利"
  hints=["销售额涨、毛利降，说明'卖得多但赚得少'。","什么情况下会卖得多赚得少？价格变低了。"]
  feedback="销售额=量×价。价格降了，量上来了，销售额可能涨，但毛利率会被拉低。这就是为什么要同时看规模和盈利两层。"
  unlock="下次汇报时，主动把'销售额+毛利率'放在一起说，会显得你更会分析。"
}
