先凭眼力挑一挑：上面两行「离谱」的数，你觉得它们各算什么性质的问题？

:::reveal{title="看解析：逻辑错误分三类，判断标准各不同"}
数据清洗第一步，是把「明显不对」的**逻辑错误**挑出来。它们分三类，判断标准不同——单看离谱、互相打架、还是违了规矩。

> 口诀：**单看离谱叫不合理，互相打架叫矛盾，违了规矩叫违规。**

:::cards{
  title="三类逻辑错误：判断标准各不同"

  items=[

    {title:"矛盾（contradictory）", desc:"多个字段互相打架。例：销量=0却销售额=9999、金额为负却成交量>0。特征：必须跨字段校验，常用 销量×单价≈金额 做一致性检查。"},
    {title:"违规（violating rules）", desc:"违反既定业务规则或约束。例：同一订单号两次、必填字段为空、日期格式非法、商品ID不在主数据。特征：对照规则清单逐条核对，最易被遗漏。"}

:::question{title="不合理：哪些数『单看就离谱』？", hint="先想：金额=-50、年龄=256、转化率=350%——这些不用看别的字段，就能判错吗？"}
mentor 说：有些数你连别的列都不用看，光这一格就离谱。你觉得上面三个例子，归到哪一类最合适？

:::reveal{title="看解析：不合理——单字段即可判定的离谱值"}
**不合理（implausible）** 指数值落在业务不可能出现的范围，靠**单个字段**就能判定，不需要别的列来对照。

- 金额 = -50：钱不可能是负数（除非是退款冲抵，但正常成交不会）。
- 年龄 = 256：人类年龄不可能超过约 120。
- 转化率 = 350%：转化率是「成交÷访问」，不可能超过 100%。

:::question{title="矛盾：单看没事，放一起就打架？", hint="先想：销量=0 却 销售额=9999、金额为负却成交量>0——为什么必须跨字段才看得出来？"}
小北又发现一行：销量为 0，销售额却是 9999。单独看「销量 0」和「销售额 9999」都没毛病，可合起来就别扭。你觉得问题出在哪？

:::reveal{title="看解析：矛盾——必须跨字段校验才现形"}
**矛盾（contradictory）** 是多个字段互相冲突，单看每个字段都正常，但组合起来违反业务逻辑。最常用 **销量 × 单价 ≈ 金额** 做一致性检查。

- 销量 = 0 却 销售额 = 9999：没卖东西却有大额，矛盾。
- 金额为负 却 成交量 > 0：卖了东西钱却变负，矛盾。
- 库存减少 却 无出库记录：账实不符，矛盾。

:::cards{
  title="识别『矛盾』：用公式对账"
  theme="amber"
  items=[
    {title:"销量 × 单价 ≈ 金额", desc:"三者应自洽；不等即矛盾，是最常用的一致性校验。"},
    {title:"库存变动 ↔ 出入库", desc:"库存减少或增加，应能对应一笔出入库记录。"}
  ]
}
:::

:::question{title="违规：不是数错了，是『违了规矩』？", hint="先想：同一订单号出现两次、必填字段为空、商品ID不在主数据——这些算哪类？"}
小北比对主数据时发现：有订单号重复了，还有必填的客户姓名为空。这些数字本身没离谱，问题在哪一类？

:::reveal{title="看解析：违规——违反既定业务规则"}
**违规（violating rules）** 指违反既定业务规则或约束。数字本身可能「正常」，但违背了规矩，最容易被遗漏。

- 同一订单号出现两次：主键应唯一，重复即违规。
- 必填字段为空：如客户姓名、收货地址缺失，违规。
- 日期格式非法：如写成「2024/13/40」，违规。
- 商品 ID 不在主数据：引用了不存在的商品，违规。

:::question{title="清洗方法：按什么顺序洗，才不放大误差？", hint="先想：标注、去重、范围校验、一致性校验、修正剔除——先干哪件？"}
mentor 让小北动手洗这张表。方法不少：标注、去重、范围校验、一致性校验、修正或剔除。你觉得该按什么顺序？

:::reveal{title="看解析：五类清洗方法 + 黄金顺序"}
清洗不是乱删，而是按方法分层处理。

| 方法 | 做什么 | 适用 |
| --- | --- | --- |
| 标注 | 给行打错误类型标签，先不删 | 全部三类 |
| 去重 | 按主键删重复记录 | 违规（重单） |
| 范围校验 | 设 min/max，超界即标 | 不合理 |
| 一致性校验 | 跨字段公式核对 | 矛盾 |
| 修正 / 剔除 | 能修则修（如负号反转），不能修则置空或删 | 视情况 |

> 黄金顺序：**先去重 → 再查不合理 → 最后查矛盾与违规**。因为重复行会放大后面所有统计误差。

  title="黄金顺序为什么这样排"

  items=[
    {title:"先去重", desc:"重复行会让后续计数、求和、比率全部失真，必须最先清掉。"},
    {title:"再查不合理", desc:"用范围校验快速标出单字段离谱值。"},
    {title:"最后查矛盾/违规", desc:"跨字段与规则核对，放在数据去重、瘦身之后最稳。"}
  ]
}
