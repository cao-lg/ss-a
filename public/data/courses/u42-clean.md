## 一、核心要点：三类逻辑错误

数据清洗第一步，是把“明显不对”的**逻辑错误**挑出来。它们分三类，判断标准不同：

:::cards{
  title="三类逻辑错误：判断标准各不同"
  theme="coral"
  items=[
    {title:"不合理（implausible）", desc:"数值落在业务不可能出现的范围。例：金额=-50、年龄=256、转化率=350%。特征：单字段即可判定，不依赖别的字段。"},
    {title:"矛盾（contradictory）", desc:"多个字段互相打架。例：销量=0却销售额=9999、金额为负却成交量>0、库存减少却无出库。特征：必须跨字段校验，常用 销量×单价≈金额 做一致性检查。"},
    {title:"违规（violating rules）", desc:"违反既定业务规则或约束。例：同一订单号出现两次、必填字段为空、日期格式非法、商品ID不在主数据。特征：对照规则清单逐条核对，最易被遗漏。"}
  ]
}

> 口诀：**单看离谱叫不合理，互相打架叫矛盾，违了规矩叫违规。**

:::checkpoint{type="fill" question="补全：销量=0 但销售额=9999，属于 ___ 错误（不合理/矛盾/违规）" answer="矛盾" feedback="单字段看不出问题，是跨字段互相打架，所以是矛盾。"}

## 二、清洗方法

| 方法 | 做什么 | 适用 |
| --- | --- | --- |
| 标注 | 给行打错误类型标签，先不删 | 全部三类 |
| 去重 | 按主键删重复记录 | 违规（重单） |
| 范围校验 | 设 min/max，超界即标 | 不合理 |
| 一致性校验 | 跨字段公式核对 | 矛盾 |
| 修正 / 剔除 | 能修则修（如负号反转），不能修则置空或删 | 视情况 |

> 黄金顺序：**先去重 → 再查不合理 → 最后查矛盾与违规**。因为重复行会放大后面所有统计误差。
