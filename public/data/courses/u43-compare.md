先凭直觉答一句——同样一组数「涨了 10%」，如果跟去年比、跟竞品比、跟目标比，讲出来的故事会一样吗？你该先定哪个「维度」？

:::reveal{title="看解析：对比不是随便比，先定『维度』"}
「对比」不是随便比，得先选**维度**，结论才站得住。五个常用维度覆盖了一句话里「跟谁比、比什么」的所有可能。

> 同一组数，跟「去年」比和跟「目标」比，讲出来的故事可以完全不同——**先定维度，再下结论**。

:::cards{
  title="对比分析五维度：先定维度再下结论"
  theme="coral"
  items=[
    {title:"时间", desc:"今年 vs 去年（同比YoY）、本月 vs 上月（环比MoM），看『变了多少』。"},
    {title:"空间", desc:"华东 vs 华南、线上 vs 线下，看『哪里强』。"},
    {title:"类别", desc:"品类A vs 品类B、客群分层，看『结构差异』。"},
    {title:"目标", desc:"实际 vs 目标 / KPI，看『达标没』。"},
    {title:"竞争", desc:"自家 vs 竞品、vs 行业均值，看『排第几』。"}
  ]
}

:::question{title="时间 / 空间 / 类别：三种『比』分别在看什么？", hint="先想：『华东比华南好』『品类A比品类B好』『今年比去年同期好』，分别是哪三个维度？"}
小北要给老板讲三句话：「华东比华南卖得好」「品类A比品类B卖得好」「今年比去年同期好」。你觉得这三句各用了哪个维度？

:::reveal{title="看解析：时间看变化、空间看强弱、类别看结构"}
前三个维度，分别对应「变化、强弱、结构」三种完全不同的业务问题。

老板又抛来两句：「这个月 KPI 达标没？」「我们在行业里排第几？」你觉得这两问分别对应哪两个维度？

:::question{title="维度该配什么图？区域销售额大小用哪张图最直观？", hint="先猜：要比较各区域销售额谁大谁小，折线图、柱状图、饼图哪个最合适？"}
mentor 说：维度定了，图也得选对。小北要比较「各区域销售额大小」，你觉得哪张图一眼就能比出高低？

:::reveal{title="看解析：维度决定图表，别乱配"}
不同维度适合不同图表——配错图，结论就被埋了。

| 对比维度 | 推荐图表 | 理由 |
| --- | --- | --- |
| 时间趋势 | 折线图 | 突出「变化」 |
| 空间 / 类别 | 柱状图（分组） | 突出「谁大谁小」 |
| 构成占比 | 饼图 / 堆叠柱 | 突出「份额」 |
| 目标达成 | 子弹图 / 仪表盘 | 突出「距目标多远」 |
| 竞争对标 | 分组柱 / 雷达图 | 突出「相对位置」 |

    {title:"看份额→饼/堆叠", desc:"构成占比用饼图或堆叠柱突出结构。"}
