先凭直觉答一句——同事说「华东区空调卖得好」，能推出「华东区所有品类都好」吗？你打算怎么同时看「地区」和「品类」？

:::reveal{title="看解析：单维度会骗人，交叉分析才见真相"}
单一维度会骗人。**交叉分析** = 把两个或更多维度叠在一起看，比如 `地区 × 品类`、`渠道 × 时段`。真相藏在**交叉格**里。

- 只看「地区」：华东最好。
- 叠上「品类」：华东好，是因为空调；它的小家电其实在掉。
- 工具：透视表（pivot）快速聚合、热力图（heatmap）看密集矩阵、堆叠柱看构成。

    {title:"堆叠柱", desc:"在分类下看子分类构成，叠出结构差异。"}
  ]
}

:::question{title="单维度为什么骗人：华东好，真的是全面好？", hint="先想：叠上『品类』后，华东的小家电在掉——这说明了什么？"}
小北按 mentor 说的叠了维度：华东整体第一，但「小家电」品类其实在下滑。光看「地区」维度时，你以为华东全面好——问题出在哪？

:::reveal{title="看解析：单维度会掩盖结构，真相在交叉格"}
只看一个维度（如地区），会把内部的结构差异「平均掉」。叠上第二个维度（如品类），才能看到谁在撑、谁在掉。

  ]
}

:::question{title="陷阱一：相关 ≠ 因果，你被哪个『伪相关』骗过？", hint="先想：冰淇淋销量和溺水人数正相关，但因果是『天热』——销售里也有这种假关系吗？"}
小北发现「会员数」和「复购」正相关，激动地说「拉新会员就能提升复购」。mentor 摇头——你觉得问题在哪？

:::reveal{title="看解析：交叉分析两陷阱（一）——相关 ≠ 因果"}

:::question{title="陷阱二：辛普森悖论，分组都涨、合计却跌？", hint="先想：两个渠道各自的转化率都涨了，总转化率却跌了——这可能吗？问题出在哪？"}
小北汇报：A、B 两个渠道各自的转化率这个月都涨了，可算总账，整体转化率却跌了。这可能吗？

:::reveal{title="看解析：交叉分析两陷阱（二）——辛普森悖论"}
分组看 A 胜 B，合计却 B 胜 A——这就是**辛普森悖论**。

- 例：两渠道各自转化率都涨，总转化率却跌——因为**流量结构变了**（低转化的渠道占比变大）。
- 提醒：别只看分组或只看合计，要同时看交叉结构。

:::cards{
  title="识别『辛普森悖论』"
  theme="coral"
  items=[
    {title:"看权重结构", desc:"合计被各分组占比（权重）影响，结构一变，合计方向就反转。"},
    {title:"分组与合计对照", desc:"同时看分组结论和整体结论，不一致时要查流量/样本结构。"}
  ]
}
:::
