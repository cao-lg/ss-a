## 一、核心要点：什么是交叉分析

单一维度会骗人。**交叉分析** = 把两个或更多维度叠在一起看，比如 `地区 × 品类`、`渠道 × 时段`。

- 只看"地区"：华东最好。
- 叠上"品类"：华东好，是因为空调；它的小家电其实在掉。
- 真相藏在**交叉格**里。

> 工具：透视表（pivot）快速聚合、热力图（heatmap）看密集矩阵、堆叠柱看构成。

## 二、怎么选图

| 场景 | 图 |
| --- | --- |
| 二维均值 / 密度矩阵 | 热力图 |
| 分类 + 子分类 | 堆叠柱 / 分组柱 |
| 多维下钻 | 透视表 + 切片器 |
