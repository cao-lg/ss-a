主管甩来一串数字：没有上升下降，只是忽上忽下。你作为新人，会怎么给出一个"稳一点"的下周预测？先想清楚——这串数据到底属于什么类型，才好对症下药。

:::reveal{title="看解析：什么是「水平序列」"}
水平序列指数据**围绕一个稳定均值上下波动，无明显趋势与季节**。这类序列的短期预测常用两类方法：**移动平均法**和**指数平滑法**。

:::question{title="移动平均法：最近几期的平均，就是下期预测？", hint="先算一笔：最近3期[120,130,140]，下期预测该填多少？"}
主管要个数，你决定先用移动平均。最近3期销量是 120、130、140，下期预测该填多少？先自己算，再核对。

:::reveal{title="看解析：移动平均怎么算"}
移动平均法：用**最近 N 期实际值的平均**作为下一期预测：

> 第 t+1 期预测 = 最近 N 期实际值之和 ÷ N（N 即窗口大小，N 越大越平滑、也越滞后）。

**算例**：最近3期销量 [120, 130, 140]，则下期预测 = (120+130+140)/3 = **130**。

  title="移动平均的两个要点"

  items=[
    {title:"窗口 N", desc:"取最近 N 期求平均；N 越大越平滑，但也越滞后、反应越慢。"},
    {title:"适用场景", desc:"数据平稳、想简单快速给出预测时最合适。"}
  ]
}

:::question{title="指数平滑：α 怎么让「近期」更管用？", hint="先想：为什么有的预测更「跟手」，有的更「平滑」？"}
主管嫌移动平均要存整段窗口。你换指数平滑，设 α=0.5。为什么 α 越大预测越"跟手"？先说出你的直觉。

:::reveal{title="看解析：指数平滑的赋权逻辑"}
指数平滑给**近期更大权重、递归平滑**。核心公式：

:::formula{
  title="指数平滑：近期权重更大"
  expr="F_{t+1} = α · A_t + (1−α) · F_t"
  vars=[{sym:"F_{t+1}", mean:"下一期预测值"}, {sym:"A_t", mean:"本期实际值"}, {sym:"F_t", mean:"上期预测值"}, {sym:"α", mean:"平滑系数，∈(0,1]，越大越看重最近一期"}]
  note="α 越大越看重最近一期；近期被放大权重，预测更'跟手'。"
}

**算例**：设 F₁ = A₁ = 130，α = 0.5，后续实际值 [130, 140]：
- F₂ = 0.5×130 + 0.5×130 = 130
- F₃ = 0.5×130 + 0.5×140 = 135

α 本质是"本期实际"与"上期预测"的加权平均：**α 越大，越相信最近一期**。

:::cards{
  title="指数平滑的两个要点"
  theme="coral"
  items=[
    {title:"α 的取舍", desc:"α 大→紧跟近期、反应快但易抖动；α 小→更平滑、抗噪但滞后。"},
    {title:"不用存窗口", desc:"只需上期预测 F_t 与本期实际 A_t，递归即可，省存储。"}
  ]
}
:::
