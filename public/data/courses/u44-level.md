# 任务：水平序列预测

## 学习目标

- 掌握移动平均法
- 掌握指数平滑法（α）

水平序列：数据围绕一个稳定均值上下波动，无明显趋势与季节。常用两类方法做短期预测。

## 一、移动平均法

用最近 N 期实际值的平均，作为下一期预测：

:::checkpoint{type="fill" question="补全：第 t+1 期移动平均预测 = 最近 ___ 期实际值的平均" answer="N" feedback="移动平均取最近 N 期（窗口大小）求平均，N 越大越平滑、也越滞后。"}

例：最近 3 期销量 [120, 130, 140]，则下期预测 = (120+130+140)/3 = 130。

## 二、指数平滑法

给近期更大权重，递归平滑。核心公式如下：

:::formula{
  title="指数平滑：近期权重更大"
  expr="F_{t+1} = α · A_t + (1−α) · F_t"
  vars=[{sym:"F_{t+1}", mean:"下一期预测值"}, {sym:"A_t", mean:"本期实际值"}, {sym:"F_t", mean:"上期预测值"}, {sym:"α", mean:"平滑系数，∈(0,1]，越大越看重最近一期"}]
  note="α 越大越看重最近一期；近期被放大权重，预测更'跟手'。"
}

**算例**：设 F₁ = A₁ = 130，α = 0.5，后续实际值 [130, 140]：
- F₂ = 0.5 × 130 + 0.5 × 130 = 130
- F₃ = 0.5 × 130 + 0.5 × 140 = 135

:::checkpoint{type="fill" question="补全：指数平滑预测 = α × 本期实际值 + (1−α) × ___" answer="上期预测值" feedback="指数平滑是'上一期预测'与'本期实际'的加权平均，F 代表上期预测值。"}
