:::reveal{title="看解析：什么是「趋势预测」"}
数据长期向上 / 向下，用一条**趋势线**把方向说清，并外推未来。常见三类，按弯曲程度选：

:::question{title="怎么判断这条线靠不靠谱？", hint="先想：散点没完全贴线，拿什么数衡量『贴得紧不紧』？"}
老板问："你这条线准不准？" 你没法只靠肉眼。你觉得，该用哪个指标来给"拟合得好不好"打个分？

:::reveal{title="看解析：用 R² 判断拟合优度"}
衡量趋势线贴不贴散点，看**拟合优度 R²**：

:::formula{
  title="R²：拟合优度"
  expr="R² = 1 − SS_res / SS_tot"
  vars=[{sym:"R²", mean:"拟合优度，取值 0~1，越接近 1 越好"}, {sym:"SS_res", mean:"残差平方和（实际值与预测值之差的平方和）"}, {sym:"SS_tot", mean:"总平方和（实际值与均值之差的平方和）"}]
  note="R² 接近 1：散点紧贴趋势线，外推可信；R² 偏低：线只是'勉强穿过'，外推风险大。"
}

> R² 是这条线的"成绩单"——越高，老板越敢拿去外推。

:::question{title="线性最小二乘：这条线是怎么「算」出来的？", hint="先想：要画出最贴合的线，斜率 b 和截距 a 各看什么？"}
老板要的是具体参数。你选线性最小二乘。你觉得，斜率 b（线的陡缓）和截距 a（线的起点）分别由什么决定？先给公式。

:::reveal{title="看解析：线性最小二乘公式"}
线性最小二乘（最常用）给出最优直线与参数：

:::formula{
  title="线性最小二乘"
  expr="b = Σ((x−x̄)(y−ȳ)) / Σ(x−x̄)² ， a = ȳ − b·x̄"
  vars=[{sym:"b", mean:"斜率，线的陡缓"}, {sym:"a", mean:"截距，x=0 时的起点"}, {sym:"x̄, ȳ", mean:"x 与 y 的均值"}]
  note="中心化后求协方差与方差之比得斜率 b，再回推截距 a——这就是『最小二乘』的最优直线。"
}

> 有了 a、b，趋势线 y = a + b·x 就能写出来，并用于外推。

:::cards{
  title="最小二乘的两个要点"
  theme="mint"
  items=[
    {title:"b 看协方差", desc:"b = 协方差 / x 方差，反映 x 每动一点 y 动多少。"},
    {title:"a 由 b 回推", desc:"a = ȳ − b·x̄，保证线穿过数据中心。"}
  ]
}
:::
:::checkpoint{
  type="multiple_choice"
  scenario="老板让你写清算法。"

  options=["b = Σ((x−x̄)(y−ȳ)) / Σ(x−x̄)²，a = ȳ − b·x̄", "b = ȳ − a·x̄，a 随意取", "b = Σ(x·y) / Σ(x²)，无需中心化", "a = Σ(y)/n，与 b 无关"]
  answer="b = Σ((x−x̄)(y−ȳ)) / Σ(x−x̄)²，a = ȳ − b·x̄"
  hints=["先算均值 x̄、ȳ 做中心化。", "a 由 b 回推，不是随便给。"]
  feedback="正确——中心化后协方差比方差得 b，再回推 a，这条线才最优。"
