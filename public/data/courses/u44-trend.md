## 一、核心要点：趋势线拟合

数据长期向上 / 向下，用一条**趋势线**把方向说清，并外推未来。常见三类：

- **线性**：`y = a + b·x`，匀速增长。
- **多项式**：带拐弯的曲线（二次 / 三次）。
- **指数**：加速增长 `y = a·e^(b·x)`。

:::checkpoint{type="fill" question="补全：R² 越接近 ___，趋势线拟合越好（0/1）" answer="1" feedback="R² 是拟合优度，1 表示完全贴合。"}

## 二、怎么判断"靠不靠谱"：R²

> **R² = 1 − SS_res / SS_tot**，取值 0~1。

- R² 接近 1：散点紧贴趋势线，外推可信。
- R² 偏低：线只是"勉强穿过"，外推风险大。

**线性最小二乘**（最常用）：
`b = Σ((x−x̄)(y−ȳ)) / Σ(x−x̄)²`，`a = ȳ − b·x̄`。

## 三、外推三诫

1. **别超出数据范围太远**：趋势会拐点。
2. **警惕黑天鹅**：疫情、政策会让历史作废。
3. **配合季节 / 水平模型**：纯趋势忽略波动。
