主管要智能体"把预测和决策一起出"。你作为分析师，第一反应是：它一张嘴就给个数字，你敢签字吗？它动手算之前，最该先做什么？

:::reveal{title="看解析：智能体第一步——先分类，再选模型"}
智能体（Agent）做预测，第一步不是算，而是**判断序列属于哪类**，再匹配模型：

| 序列特征 | 匹配模型 | 代表单元 |
| --- | --- | --- |
| 无趋势无季节、绕均值波动 | **水平**（移动平均 / 指数平滑） | u44-level |
| 周期性起伏明显 | **季节**（季节指数） | u44-season |
| 长期单调上升 / 下降 | **趋势**（趋势线 + R²） | u44-trend |

> 让智能体"先亮依据，再给数"：它必须先说出"这是哪类序列、用了什么模型"，你才敢签字。

:::cards{
  title="智能体的第一性原则"
  theme="violet"
  items=[
    {title:"先分类", desc:"判明序列是水平/季节/趋势，再谈算法。"},
    {title:"再选模型", desc:"分类错了，预测再花哨也不可信。"},
    {title:"先亮依据", desc:"它得先说清『哪类序列、什么模型』，你才敢签字。"}
  ]
}
:::

:::question{title="三类序列，怎么一一匹配模型？", hint="先练：某品『夏季高、冬季低、逐年平稳』，该配哪类模型？"}
分类不是背定义，得能落地。主管抛了个例子：某商品"夏季高、冬季低、但逐年平稳"。你觉得智能体该给它配哪类模型？先判断。

:::reveal{title="看解析：特征 → 模型的映射"}
把三类特征与模型再钉死一遍：

:::cards{
  title="三类序列的匹配口诀"
  theme="mint"
  items=[
    {title:"绕均值波动", desc:"无趋势无季节 → 水平（移动平均 / 指数平滑）。"},
    {title:"周期起伏明显", desc:"如夏季高冬季低 → 季节（季节指数）。"},
    {title:"长期单调升降", desc:"如逐年增长 → 趋势（趋势线 + R²）。"}
  ]
}

> "夏季高、冬季低、逐年平稳"=周期性起伏明显 → 配**季节**模型，而不是水平（它有明显的季节峰谷）。

:::cards{
  title="一个易错点"
  theme="coral"
  items=[
    {title:"别被『逐年平稳』骗", desc:"『逐年平稳』指年与年之间稳，但年内夏高冬低是强季节信号——仍归季节类。"}
  ]
}

:::question{title="智能体的「决策依据」该长什么样？", hint="先想：一条你能签字的建议，除了数字还得写清什么？"}
主管说："你敢签字的建议，不能只甩一个数字。"你觉得，一条可信的智能体建议，必须写清哪几段东西？

:::reveal{title="看解析：可信建议的四段依据"}
一条可信的建议应当包含四段依据：

:::steps{
  theme="mint"
  title="可信建议的四段依据"
  steps=[
    {title:"数据", desc:"用了哪段、多少样本。"},

    {title:"假设", desc:"大促 / 节假日如何处理。"},
    {title:"动作", desc:"备多少、往哪倾，及风险边界（如'若需求超预测 20%，将断货'）。"}
  ]
}
:::
