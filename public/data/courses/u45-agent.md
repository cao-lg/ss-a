# 任务：智能体综合预测案例

## 学习目标
- 多模型匹配（水平/季节/趋势）
- 产出备货与渠道决策建议

## 一、核心要点：先分类，再选模型

智能体（Agent）做预测，第一步不是算，而是**判断序列属于哪类**，再匹配模型：

| 序列特征 | 匹配模型 | 代表单元 |
| --- | --- | --- |
| 无趋势无季节、绕均值波动 | **水平**（移动平均 / 指数平滑） | u44-level |
| 周期性起伏明显 | **季节**（季节指数） | u44-season |
| 长期单调上升 / 下降 | **趋势**（趋势线 + R²） | u44-trend |

> 让智能体"先亮依据，再给数"：它必须先说出"这是哪类序列、用了什么模型"，你才敢签字。

:::checkpoint{type="fill" question="补全：无明显趋势与季节、围绕均值波动 → 选 ___ 模型（水平/季节/趋势）" answer="水平" feedback="平稳波动配水平模型。"}

## 二、从预测到决策：备货与渠道

预测只是起点，业务要的是**动作**：

- **备货建议**：需求预测 → 安全库存 → 再订货点。`再订货点 = 日均需求 × 提前期 + 安全库存`。
- **渠道倾斜**：把预算压向**边际 ROI 高**的渠道；用对比 / 交叉分析定位。

:::challenge{id="u45-agent_c1" type="fill" title="进阶挑战" instruction="某品“夏季高、冬季低、逐年平稳”，应匹配哪类模型？填空：___" answer="季节" feedback="周期性起伏明显，配季节模型。"}

## 三、智能体的"决策依据"该长什么样

一条可信的建议应当包含：
1. **数据**：用了哪段、多少样本；
2. **模型**：选了哪类、为什么；
3. **假设**：大促 / 节假日如何处理；
4. **动作**：备多少、往哪倾，及**风险边界**（如"若需求超预测 20%，将断货"）。
