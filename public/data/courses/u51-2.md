### 服务规模层（广度）：解决“有多少服务需求”

聚焦“服务需求总量”与“渠道覆盖范围”，形成**咨询量 → 接待量 → 问题量**的递进关系——总量逐级收敛，缺口就是流失与待挖掘的信号。

:::funnel{
  theme="mint"
  title="咨询量 → 接待量 → 问题量"
  steps=[
    {"name":"咨询量","desc":"客户发起的服务咨询总次数（含未接入）。反映服务需求规模：偏低=客户自助能力强；偏高=排查产品或促销影响。","gap":"未接入部分 = 潜在流失"},
    {"name":"接待量","desc":"客服成功接起的咨询次数。区分咨询与接待、评估服务承载能力；占比偏低=存在客户流失。","gap":"非问题类咨询被分流"},
    {"name":"问题量","desc":"客户提交的具体问题数量（按维度统计）。与咨询量结合判断问题集中度，为服务优化提供依据。"}
  ]
}

### 服务效率层（速度）：解决“多快能解决问题”

聚焦“响应速度”与“处理速度”全链路，拆解关键节点形成**排队 → 首响 → 响应 → 处理**的时效链条——越靠后、越久，客户体验越差。

:::flow{
  theme="amber"
  title="一次咨询的时效链路"
  steps=[
    {"name":"排队时长","desc":"客户接入客服前的平均等待时间。过长=增加坐席或优化分流策略。"},
    {"name":"首次响应时间","desc":"客户发起请求（工单/在线/电话）到客服首次回应的间隔，是时效起点。"},
    {"name":"平均响应时长","desc":"客服首次回复客户的时间平均值。异常=排查坐席负载或系统问题。","benchmark":"30秒–2分钟"},
    {"name":"平均处理时长","desc":"客服完成一次完整咨询的平均时间。过长=优化话术/知识库；过短=可能影响质量。"}
  ]
}

### 服务质量层（深度）：解决“问题解决得怎么样”

从“满意度 / 解决质量 / 复发与差错”三维度评估服务实质效果，挖掘短板根源。

:::kpi{
  theme="violet"
  title="六个质量指标，各自盯一个漏洞"
  items=[
    {"name":"客户满意度","def":"单次服务满意度评分均值（通常1-5分制）。","signal":"低于4分需深入分析原因。"},
    {"name":"问题解决率","def":"客户问题得到有效解决的比例。","signal":"偏低=排查归类准确性或方案有效性。"},
    {"name":"首次解决率（FCR）","def":"问题在首次咨询中即被解决的比例。","signal":"偏低=加强培训或优化流程（基准70%-85%）。"},
    {"name":"问题复发率","def":"同一客户因相同问题再次咨询的比例。","signal":"高=问题未根治，需优化知识库/流程。"},
    {"name":"服务差错率","def":"出现处理失误的服务量占比（信息告知/工单录入/方案偏差等）。","signal":"反映服务规范性。"},
    {"name":"投诉率","def":"客户对服务进行投诉的比例。","signal":"识别严重问题，需重点溯源分析。"}
  ]
}

### 服务价值层（效度）：解决“服务是否值得”

聚焦“成本与效益平衡”，把服务投入换算成可量化的商业价值，是服务效能的终极衡量。

:::kpi{
  title="价值层：从成本到口碑"
  items=[
    {"name":"单次服务成本","def":"服务总成本 / 服务量（含人力、系统、其他成本）。","signal":"持续跟踪优化效率。"},
    {"name":"客户留存率","def":"接受过服务的客户在一定周期内留存的比例。","signal":"衡量服务对客关维护的贡献。"},
    {"name":"推荐意愿（NPS）","def":"客户推荐产品或服务的意愿度（问卷评分0-10）。","signal":"高=服务转化为口碑效应。"},
    {"name":"服务转化价值","def":"通过服务促成的新增或挽回订单价值。","signal":"量化服务商业价值，为部门定位提供依据。"}
  ]
}

带计算公式的指标，直接看式子更清楚：

:::formula{
  title="服务关联复购率"
  expr="服务后复购客户数 / 总服务客户数 × 100%"
  vars=[{"sym":"服务后复购客户数","mean":"接受服务后指定周期内（如3个月）产生复购的客户"},{"sym":"总服务客户数","mean":"统计周期内接受过服务的客户总量"}]
  note="衡量服务对客户留存的拉动，是服务长期价值的体现。"
}

:::formula{
  title="新老客户占比"
  expr="新客户占比 = 新客户量 / 总客户数 × 100%；老客户占比 = 1 − 新客户占比"
  vars=[{"sym":"新客户量","mean":"统计周期内首次出现的客户数"},{"sym":"总客户数","mean":"客户总量（新+老），两者占比之和为100%"}]
  note="评估客户结构的稳定性与增长潜力。"
}

四层指标汇总成一张速查表，方便随时回看：

| 指标层级 | 指标名称 | 内涵 | 计算应用 |
| --- | --- | --- | --- |
| 服务规模层（广度） | 咨询量 | 服务咨询总次数（含未接入） | 统计周期内所有客户发起的咨询请求 |
| 服务规模层（广度） | 接待量 | 客服成功接起的咨询次数 | 成功建立连接的咨询数 |
| 服务规模层（广度） | 问题量 | 客户提交的具体问题数量（按问题维度统计） | 按退换货、物流、产品使用等维度归类统计 |
| 服务效率层（速度） | 平均响应时长 | 客服首次回复客户的平均时间 | 所有咨询首次回复时长的总和/咨询数 |
| 服务效率层（速度） | 平均处理时长 | 客服完成一次完整咨询的平均时间 | 所有咨询处理时长的总和/咨询数 |
| 服务效率层（速度） | 首次解决率 | 客户问题在首次咨询中得到解决的比例 | 首次解决的问题量/总问题量×100% |
| 服务效率层（速度） | 排队时长 | 客户在接入客服前的平均等待时间 | 所有客户排队时长的总和/排队客户数 |
| 服务质量层（深度） | 客户满意度 | 客户对单次服务满意度的平均评分 | 所有服务评分总和/服务次数（通常1-5分制） |
| 服务质量层（深度） | 问题解决率 | 定义：客户问题得到有效解决的比例 | 已解决问题量/总问题量×100% |
| 服务质量层（深度） | 首次解决率（FCR） | 客户首次发起服务请求即无需二次跟进的比例 | 首次解决的问题量 / 总问题量 ×100% |
| 服务质量层（深度） | 问题复发率 | 同一客户因相同问题再次咨询的比例 | 复发问题量/总问题量×100% |
| 服务质量层（深度） | 服务差错率 | 服务过程中出现处理失误的比例 | 出现差错的服务量 / 总服务量 ×100% |
| 服务质量层（深度） | 投诉率 | 客户对服务进行投诉的比例 | 投诉次数/服务量×100% |
| 服务价值层（效度） | 单次服务成本 | 每次服务的成本 | （人力成本+系统成本+其他成本）/服务量 |
| 服务价值层（效度） | 客户留存率 | 接受过服务的客户在一定周期内留存的比例 | 留存客户数/服务客户数×100% |
| 服务价值层（效度） | 推荐意愿（NPS） | 客户推荐产品或服务的意愿度 | 推荐者占比-贬损者占比（问卷评分0-10分） |
| 服务价值层（效度） | 服务关联复购率 | 客户接受服务后在指定周期内产生复购的比例 | 服务后复购客户数 / 总服务客户数 ×100% |
| 服务价值层（效度） | 新老客户占比 | 新客户和老客户在总客户数中的比例 | 新客户占比 = 新客户量 / 总客户数 ×100% |
| 服务价值层（效度） | 服务转化价值 | 通过服务促成的新增订单或挽回订单价值 | 服务促成的订单金额总和 |
