## 搭建步骤：从建表到表间联动

把客户信息与订单拆成两张表，再用关联字段把它们串起来，是后面所有 AI 打标签、RFM 分层能跑起来的前提。

:::steps{
  title="数据底座搭建七步法"
  steps=[
    {title:"新建多维表格", desc:"进入飞书工作台 → 多维表格 → 新建，命名为「焕新家电-客户管理系统」，依次创建「客户基础信息表」与「订单数据表」。"},
    {title:"导入 Excel 数据", desc:"导入 excel 数据，系统自动创建以上两张表的结构与内容。"},

    {title:"订单表引用姓名", desc:"新增「客户姓名」字段，查找引用客户基础信息表的「姓名」字段，查询条件设为「客户ID」等于「客户ID」。（图5-15）"},
    {title:"客户表关联订单", desc:"「客户基础信息表」新增「累计消费金额」字段，并新增「单向关联」字段，单项关联订单表。（图5-16）"},
    {title:"客户表汇总金额", desc:"查找引用订单记录表的「金额」字段，查询条件「客户ID」等于「客户ID」，计算方式设为「求和」。（图5-17）"},
    {title:"验证联动", desc:"新增一条订单信息，客户基础信息表中该客户的累计消费金额应自动更新。（图5-18）"}
  ]
}

> 关联搭好后，订单与客户的每一次变动都会自动回流——这正是后面客户等级、累计消费能实时计算的关键。

## 字段设计详解

两张表的字段设计如下，作为后续录入与关联的配置基准。

| 字段名称 | 字段类型 | 配置说明 |
| --- | --- | --- |
| 客户ID | 自动编号 | 自动生成，格式：KH2024+四位序号 |
| 姓名 | 文本 | 单行文本，必填项 |
| 手机号 | 电话号码 | 自动识别手机号格式，唯一性校验 |
| 来源渠道 | 单选 | 选项：京东旗舰店、天猫旗舰店、抖音直播、门店自访、老客户推荐、美团/大众点评 |
| 首次购买日期 | 日期 | 格式：YYYY-MM-DD |
| 购买产品类型 | 多选 | 选项：冰箱、洗衣机、空调、小家电、全屋套餐 |
| 客户等级 | 单选 | 选项：A类（高价值）、B类（潜力）、C类（普通）、D类（新客户） |
| 累计消费金额 | 数字 | 关联订单表自动汇总，保留2位小数 |
| 最近购买日期 | 日期 | 关联订单表自动提取最新订单日期 |
| 复购次数 | 数字 | 统计关联订单数量 |

| 字段名称 | 字段类型 | 配置说明 |
| --- | --- | --- |
| 订单号 | 自动编号 | 格式：DD202401+三位序号 |
| 客户ID | 关联记录 | 关联"客户基础信息表"，显示客户姓名 |
| 产品名称 | 文本 | 单行文本，如：海尔冰箱BCD-520W |
| 品牌 | 单选 | 选项：海尔、格力、美的、小天鹅、西门子、戴森、九阳、苏泊尔等 |
| 产品分类 | 单选 | 选项：冰箱、洗衣机、空调、小家电、全屋套餐 |
| 金额（元） | 数字 | 货币格式，保留2位小数 |
| 购买时间 | 日期+时间 | 精确到分钟 |
| 支付状态 | 单选 | 选项：已支付、待支付、已退款 |
| 发票状态 | 单选 | 选项：已开票、待开票、未开票 |
