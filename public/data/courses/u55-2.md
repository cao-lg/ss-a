（一）创建多维表格
创建表格
打开飞书，进入“工作台”点击“多维表格”应用，点击“新建”→“新建多维表格”，将表格命名为“焕新家电-客户管理系统”依次创建客户基础信息表和订单数据表。
字段设计详解
表5-6 客户基础信息表
表5-7 订单记录表
创建表格
导入excel数据，自动创建以上两张表。
（二）表间关联设置
在“订单数据表”中显示客户姓名
新增“涉及客户”字段，单项关联客户基础信息表
图5-14 订单表单项关联客户基础信息表
新增“客户姓名”字段，查找引用客户基础信息表的姓名字段，并设置查询条件为“客户ID”等于“客户ID”。
图5-15 订单表引用客户姓名
客户基础信息表自动汇总客户累计消费金额
客户基础信息表新增“累计消费金额”字段，新增“单向关联”字段，单项关联订单表。
图5-16 客户基础信息表关联订单表
查找引用订单记录表的金额字段，并设置查询条件为“客户ID”等于“客户ID”，计算方式为求和。
图5-17 客户基础信息表累计消费金额设置字段设置
增加一条订单信息，客户基础信息表中该客户消费总金额自动更新。
图5-18 客户基础信息表累计消费金额自动更新

| 字段名称 | 字段类型 | 配置说明 |
| --- | --- | --- |
| 客户ID | 自动编号 | 自动生成，格式：KH2024+四位序号 |
| 姓名 | 文本 | 单行文本，必填项 |
| 手机号 | 电话号码 | 自动识别手机号格式，唯一性校验 |
| 来源渠道 | 单选 | 选项：京东旗舰店、天猫旗舰店、抖音直播、门店自访、老客户推荐、美团/大众点评 |
| 首次购买日期 | 日期 | 格式：YYYY-MM-DD |
| 购买产品类型 | 多选 | 选项：冰箱、洗衣机、空调、小家电、全屋套餐 |
| 客户等级 | 单选 | 选项：A类（高价值）、B类（潜力）、C类（普通）、D类（新客户） |
| 累计消费金额 | 数字 | 关联订单表自动汇总，保留2位小数 |
| 最近购买日期 | 日期 | 关联订单表自动提取最新订单日期 |
| 复购次数 | 数字 | 统计关联订单数量 |

| 字段名称 | 字段类型 | 配置说明 |
| --- | --- | --- |
| 订单号 | 自动编号 | 格式：DD202401+三位序号 |
| 客户ID | 关联记录 | 关联“客户基础信息表”，显示客户姓名 |
| 产品名称 | 文本 | 单行文本，如：海尔冰箱BCD-520W |
| 品牌 | 单选 | 选项：海尔、格力、美的、小天鹅、西门子、戴森、九阳、苏泊尔等 |
| 产品分类 | 单选 | 选项：冰箱、洗衣机、空调、小家电、全屋套餐 |
| 金额（元） | 数字 | 货币格式，保留2位小数 |
| 购买时间 | 日期+时间 | 精确到分钟 |
| 支付状态 | 单选 | 选项：已支付、待支付、已退款 |
| 发票状态 | 单选 | 选项：已开票、待开票、未开票 |
