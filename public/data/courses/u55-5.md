:::reveal{title="看解析：RFM，就是给客户价值打分的尺子"}
RFM 是客户价值分层的经典框架：从订单数据里算出**最近消费(Recency)**、**消费频次(Frequency)**、**消费金额(Monetary)** 三个维度，再据此给客户打分层标签。它让「谁值得重点维护」有了客观依据，而不是凭感觉。

:::question{title="R：最近消费天数，怎么算才对？", hint="先想：『最近消费』到底是拿哪个日期减哪个日期？结果越小说明什么？"}
小北卡在 R 上：要算「客户最近一次消费离现在多久」，公式该怎么列？减反了会怎样？结果越小又代表什么？

:::reveal{title="看解析：R = 今天日期 − 最近订单日期"}
R = 最近消费(Recency)：衡量客户「新鲜度」。间隔越短，客户越「新鲜」、越容易被再次激活。

:::formula{

    {sym:"今天日期", mean:"计算基准日（通常为分析当日）"},

  ]
  note="间隔越短，客户越「新鲜」、越容易被再次激活。"
}

:::question{title="F：订单次数，用什么函数一句话算出来？", hint="先想：要数『某个客户在表里出现了几次』，Excel 里该用哪个函数？"}
轮到 F：要统计某个客户在订单表里一共下了几单，手工数太笨。你觉得用哪个函数、哪两个参数，能一句话数出来？

:::reveal{title="看解析：F = COUNTIF(客户ID区域, 当前客户ID)"}
F = 消费频次(Frequency)：用 COUNTIF 统计该客户的订单次数。次数越多，客户黏性越强。

:::formula{

  theme="mint"

  ]
  note="次数越多，客户黏性越强。"
}

:::question{title="M：订单总金额，SUMIF 的第三参数是干嘛的？", hint="先想：按客户汇总金额，SUMIF 除了『条件区』和『条件值』，还要指定哪一列来求和？"}
最后是 M：要按客户把订单金额加总，得用 SUMIF。你觉得它除了「客户ID区」和「当前客户ID」，第三参数该填什么，才求和求对列？

:::reveal{title="看解析：M = SUMIF(客户ID区域, 当前客户ID, 金额区域)"}
M = 消费金额(Monetary)：用 SUMIF 按客户汇总订单总金额。金额越高，客户价值越大。

小北问：既然三个维度都能算，那我干脆只看金额最高的不就行了？你觉得，只盯一个维度会漏掉什么？

:::reveal{title="看解析：单维会偏，三维组合才均衡"}
单看一个维度会偏：只看 M 可能漏掉快流失的高频客，只看 R 又忽视价值。把 R/F/M 三维合起来，才能给客户打出均衡的分层标签。
