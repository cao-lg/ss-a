## 用 RFM 模型做客户价值分层

RFM 是客户价值分层的经典框架：从订单数据里算出 **最近消费(Recency)**、**消费频次(Frequency)**、**消费金额(Monetary)** 三个维度，再据此给客户打分层标签。三个维度的计算公式如下。

:::formula{
  title="R：最近消费天数（Recency）"
  theme="coral"
  expr="最近消费天数 = 今天日期 - 最近订单日期"
  vars=[
    {sym:"今天日期", mean:"计算基准日（通常为分析当日）"},
    {sym:"最近订单日期", mean:"该客户历史上最后一笔订单的日期"}
  ]
  note="间隔越短，客户越「新鲜」、越容易被再次激活。"
}

:::formula{
  title="F：订单次数（Frequency）"
  theme="mint"
  expr="订单次数 = COUNTIF(客户ID区域, 当前客户ID)"
  vars=[
    {sym:"客户ID区域", mean:"订单表中客户ID列的数据范围"},
    {sym:"当前客户ID", mean:"需要统计的单个客户标识"}
  ]
  note="次数越多，客户黏性越强。"
}

:::formula{
  title="M：订单总金额（Monetary）"
  theme="amber"
  expr="订单总金额 = SUMIF(客户ID区域, 当前客户ID, 金额区域)"
  vars=[
    {sym:"客户ID区域", mean:"订单表中客户ID列的数据范围"},
    {sym:"当前客户ID", mean:"需要统计的单个客户标识"},
    {sym:"金额区域", mean:"订单表中「金额（元）」列的数据范围"}
  ]
  note="金额越高，客户价值越大。"
}
